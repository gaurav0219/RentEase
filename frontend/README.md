# RentEase — Frontend

A modern rental management dashboard built with **Next.js 16**, **TypeScript**, and a custom dark-themed design system.

## Features

- 🏠 **Landing Page** — Premium animated landing with feature showcase
- 🔐 **Auth** — Login & registration with JWT token management
- 📊 **Dashboard** — Role-based views for Owners and Tenants
- 🏘️ **Property & Room Management** — Full CRUD for owners
- 📨 **Application System** — Browse rooms, apply, track status
- 📄 **Agreements** — View and download rent agreements
- 📁 **Documents** — Upload and track verification status
- 🔔 **Notifications** — Real-time bell with dropdown panel
- ⚙️ **Settings** — Profile, security, notification preferences

## Setup

```bash
# Install dependencies
npm install

# Set up environment
cp .env.example .env.local
# Edit .env.local with your backend API URL

# Start development server
npm run dev
```

The app runs on `http://localhost:3000`.
